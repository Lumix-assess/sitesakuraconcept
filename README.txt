SAKURA — versão com painel administrativo

O painel agora possui:
- cadastro inicial de usuário e senha;
- login;
- alteração de usuário e senha;
- opção para limpar o cadastro e voltar à configuração inicial;
- edição das informações do salão;
- gerenciamento dos serviços: editar, adicionar, excluir e ocultar/mostrar;
- campos PT e EN para os serviços.

IMPORTANTE:
Esta versão mantém os dados em localStorage, portanto serve como protótipo local. Para uso online em vários celulares/computadores, o painel deve ser conectado a um backend/banco de dados (por exemplo, Supabase) antes da publicação definitiva.
